# 🖥️ IT Home Lab

Hands-on IT support and sysadmin labs, built and tested in virtual machines. Every lab is documented with the commands used, the results, and what I learned.

## 🎯 Goals
- Build real Windows and Linux administration skills
- Practice troubleshooting the way a helpdesk or sysadmin would
- Learn networking and security fundamentals
- Document everything clearly enough that someone else can repeat it

## 🧪 Lab Environment
- VMware Workstation Pro
- Windows 11 Pro
- Kali linux

## ✅ Completed Labs

| Lab | What it covers |

| [NTFS Permissions with icacls](./Windows/ntfs-permissions-icacls) | Inheritance, Modify vs Read, and proving access with `runas` tests |
| [Remote Desktop (RDP)](./Windows/Remote-Desktop-RDP) | Setting up and connecting over RDP |
| [Service Management: Print Spooler](./Windows/windows-service-management-print-spooler) | Managing and troubleshooting Windows services |
